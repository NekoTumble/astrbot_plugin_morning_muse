# 🌅 晨光心语 —— AstrBot 人格化日程插件

**每日 AI 风格化日程生成，人格隔离，一键注入。**  
让每一个清晨都有独特的仪式感，让 AI 记住你的每一个身份。

📦 **仓库地址**：[https://github.com/NekoTumble/astrbot_plugin_morning_muse](https://github.com/NekoTumble/astrbot_plugin_morning_muse)

---

## ✨ 核心特性

- **一日一生成**  
  当天日程只生成一次，重启/重载不会重复浪费 Token，缓存按天持久化。
- **人格完全隔离**  
  不同人格的日程、历史参考、风格提示词全部独立存储，互不干扰。
- **批量生成与智能补齐**  
  重载插件后自动在 10 秒后补齐所有已知人格的今日日程；`/重写所有人` 全量重写不受限制，`/重写日程` 仅重写当前会话绑定的人格。
- **风格自由定制**  
  可在 WebUI 为每个人格绑定专属风格提示词。风格提示词可以留空，留空时完全不启用风格化。
- **自动人格识别**  
  自动从 AstrBot 原生会话绑定中识别当前人格，无需手动绑定指令，开箱即用。
- **人格提示词自动注入**  
  自动从 AstrBot 人格管理器获取当前人格的完整设定，作为参考发送给 LLM，让日程更贴合角色。
- **模型随心选**  
  可直接指定 AstrBot 已配置的任意模型来生成日程，不占用主对话模型。
- **智能注入**  
  每次 LLM 对话自动将当日穿搭和日程注入到系统提示，AI 回复时会自然带上人设。
- **兜底容错**  
  LLM 生成失败时自动用创意池元素拼合兜底日程，绝不会开天窗。
- **诊断报告**  
  提供 `/晨光报告` 指令，随时查看所有配置、人格状态、日程生成情况。
- **日志可查**  
  提供 `/日程日志` 指令，查看最近生成记录，方便调试。

## 📁 安装

1. 将插件文件夹 `astrbot_plugin_morning_muse` 放入 AstrBot 的插件目录（通常是 `plugins/`）。
2. 在 AstrBot 管理面板中刷新插件列表，启用「晨光心语」。
3. 重启 AstrBot 或重载插件。

> **依赖**：插件启动时会自动安装 `aiofiles`, `apscheduler`, `holidays`, `httpx`。  
> 若遇依赖问题，可在插件目录执行：
> ```bash
> pip install -r requirements.txt
> ```

## ⚙️ 配置说明

所有配置均在 AstrBot 后台可视化面板中修改，即时生效（部分需下一次生成或调度刷新）。

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| ⏰ 每日生成时间 | 每天自动生成日程的时刻，格式 HH:MM | 08:00 |
| 🤖 生成模型 | 填写 AstrBot 中已配置的模型名称，留空使用默认模型 | 空 |
| 👤 人格名 ①~③ | 需要绑定特定风格的人格名称 | 空 |
| 🎨 风格提示词 ①~③ | 对应人格的风格描述（支持多行），可为空 | 空 |
| 🎨 默认风格 | 所有人格未匹配时使用的兜底风格，可为空 | "自然亲切的语气" |
| 📆 参考历史日程天数 | 生成时参考前 N 天的日程（有助于风格连续） | 3 |
| 💬 参考近期对话条数 | 生成时参考最近 N 条聊天内容 | 5 |
| 🌅 今日主题池 | 列表形式，每天随机抽取一个 | 12 个内置主题 |
| 🌈 心情色彩池 | 列表形式，每天随机抽取一个 | 12 个内置色彩 |
| 👗 穿搭风格池 | 列表形式，每天随机抽取一个 | 15 个内置风格 |
| 🗂️ 日程类型池 | 列表形式，每天随机抽取一个 | 12 个内置类型 |
| 📝 提示词模板 | 自定义 Prompt，可使用占位符（见下文） | 内置完整模板 |

### 提示词模板占位符

- `{date_str}`：日期，如 2026年5月15日
- `{weekday}`：星期几
- `{holiday}`：当天是否为节假日
- `{persona_desc}`：当前人格与风格描述
- `{persona_prompt}`：从 AstrBot 人格管理器自动获取的完整人设
- `{daily_theme}`：今日主题
- `{mood_color}`：心情色彩
- `{outfit_style}`：穿搭风格
- `{schedule_type}`：日程类型
- `{history_schedules}`：历史日程，用于避免重复
- `{recent_chats}`：最近的聊天记录

### 模板优先级机制

内置提示词模板采用优先级分层策略来处理穿搭风格与人设冲突：

```
第1优先级：人格核心身份（从 {persona_prompt} 获取）
第2优先级：当日穿搭风格（{outfit_style}）
第3优先级：日程类型（{schedule_type}）
```

当穿搭风格与人格偏好冲突时，模板会保留人格偏好的核心元素（颜色/版型/标志性配饰），仅在局部适应当日主题，同时允许角色内心吐槽。

## 🧠 工作逻辑

1. **定时触发**：每天在设定时间自动为所有已知人格批量生成日程。
2. **按需生成**：当某个人格第一次被对话或查看日程时，若当天无缓存则立即生成。
3. **延迟补齐**：插件启动 10 秒后，自动检查并补齐所有已知人格的今日日程。
4. **风格匹配**：  
   - 插件通过 AstrBot `ConversationManager` 自动获取当前会话的 `persona_id`
   - 在 WebUI 配置中查找对应人格的风格提示词
   - 若未匹配到任何风格，则使用「默认风格」
   - 无需手动绑定指令，会话绑定什么人格就用什么风格
5. **注入系统提示**：每次 LLM 请求前，插件检测当前人格的当日日程，若存在则注入到 System Prompt，让 AI 带着"今日人设"回复。
6. **数据存储**：所有日程以 JSON 形式存储在 `data/plugin_data/astrbot_plugin_morning_muse/schedules/{人格}/schedule_YYYY-MM-DD.json`，重启不丢失。

## ❓ 常见问题

**Q：每天会重复生成很多次吗？**  
A：不会。当天日程一旦生成并保存到本地，除非使用 `重写日程` 或 `重写所有人` 指令，否则不会再次请求 LLM。

**Q：可以不注入系统提示吗？**  
A：目前每次 LLM 对话都会尝试注入，若想关闭，可以在 `main.py` 中注释掉 `on_llm_request` 装饰器下的逻辑。后续版本可能加入开关选项。

**Q：为什么我的日程是兜底生成的？**  
A：可能原因：① 模型配置错误或 API 不可用；② Prompt 模板过于复杂导致 LLM 返回格式无法解析。请查看 `/日程日志` 定位问题。

**Q：如何让新加入的人格立即生成日程？**  
A：插件重载后 10 秒会自动补齐所有已知人格的今日日程。也可以手动执行 `/重写所有人` 立即全量触发生成，或进入对应人格的会话使用 `/重写日程` 单独生成。
